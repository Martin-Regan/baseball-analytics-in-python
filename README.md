# Baseball Analytics in Python

This repository contains the code used in my *Baseball Analytics in Python* blog series, where I explore MLB data using Python.

The series covers working with baseball data in Python, analysing player and team performance, and using this data to find players your fantasy baseball team.

For full explanations of the code and analysis, see the blog series:
